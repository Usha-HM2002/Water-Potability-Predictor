# Water Potability Predictor (Flask App)

A Flask web app that predicts whether water is **safe for drinking** using a **machine learning model**.  
It includes **login/signup**, **prediction history**, and a **dashboard** with visual insights.

## Features
- User Authentication  
- ML-based Water Potability Prediction  
- Dashboard with Charts  
- SQLite Database for Users & History  

## Tech Stack
Flask | SQLite | Pandas | Scikit-learn | HTML | CSS | Bootstrap

```bash
git clone https://github.com/Usha-HM2002/Water-Potability-Predictor.git
